# Dynamic HVAC Control (Core Integration)

![Dynamic HVAC Control](brand/logo.png)

Standalone dual-probe thermostat controller for Home Assistant (pure integration without bundled frontend card).

## Installation via HACS
1. Open **HACS** > **Integrations** > **Custom repositories**.
2. Add `https://github.com/Tinkergnome621/dynamic-hvac-control-integration` as an **Integration**.
3. Install and configure via **Settings** > **Devices & Services**.
